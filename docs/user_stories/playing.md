# User Stories: Playing

As a player
I want to place my mark by clicking or tapping a cell
so that I can take my turn naturally on any device

As a player
I want the game to tell me whose turn it is
so that two of us can share one device without confusion

As a player
I want to see clearly when someone wins or the game is a draw
so that we know the round is over

As a player
I want the winning line highlighted
so that I can see how the game was won

As a player
I want to start a new game with one action
so that we can play again immediately

As a keyboard or controller user
I want to move a selection around the grid and confirm
so that I can play without a mouse or touchscreen
